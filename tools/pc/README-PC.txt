HARROW'S WAKE: LAST TOLL (PC / laptop)
Super Free AI Game Jam #2 entry - a one-night spin-off of Harrow's Wake

HOW TO PLAY
  Windows: unzip everything, then run LastToll.exe.
           Keep the data_LastToll folder next to the exe.
           If SmartScreen warns you, click "More info" then "Run anyway"
           (the game isn't code-signed).
  Linux:   unzip, then run ./LastToll.x86_64 (chmod +x it if needed).
  Headphones strongly recommended: you track the Bellman by his hand bell.

GOAL
  Find the bell rope, the bell clapper and the chapel key,
  unlock the chapel and ring the great bell before he finds you.

KEYBOARD + MOUSE
  Move ......... WASD / arrow keys      Look ...... mouse
  Run (loud) ... Shift                  Sneak ..... Ctrl or C
  Use .......... E, Space or Enter      Light ..... F
  Pause ........ Esc or P               Fullscreen  F11

GAMEPAD (Xbox layout)
  Move: left stick   Look: right stick   Use: A   Run: B / L3
  Sneak: R3   Light: LB   Pause: Start
